# Better radio
## Features

### Stream radio
- Accessible by going to 99.2 FM
- Configuration/radio station selection UI accessible by clicking the change AM/FM mode button when on any stream frequency
- Browse for radio stations to play or manually enter a valid stream URL
- Saves your stations for easy access
- Give any saved station its own FM frequency (87.5 - 108.0) from the "My stations" tab and tune to it with the dial, just like the game's own stations. 99.2 FM stays as the channel that plays whichever station you pick in the UI
- Supports MP3, AAC (including AAC+ / HE-AAC v1 and v2), FLAC and Ogg (Vorbis, Opus and FLAC) streams. HLS (.m3u8) streams are not supported
